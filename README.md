# Phishlens 🔍

> A powerful, lightweight tool for detecting, analyzing, and visualizing phishing threats. 

Phishlens is designed to help security researchers, developers, and everyday users identify malicious URLs, deceptive emails, and common phishing patterns before they can cause harm.

## 🚀 Features

- **URL Analysis:** Scans links against known malicious databases and applies heuristic checks.
- **Content Inspection:** Analyzes webpage content for suspicious elements (e.g., fake login forms, invisible text).
- **Email Header Parsing:** Extracts and verifies sender information to detect spoofing.
- **Reporting:** Generates detailed, easy-to-read reports on analyzed threats.
